# WordStrata

Source archive for the current **WordStrata** itch.io release.

The release package is a browser game built with Phaser and includes its bundled dictionary, local Phaser runtime, logo and icon assets.

Play on itch.io: https://splarg.itch.io/wordstrata

## Preservation note

The files in the initial source import are copied from the current itch.io release package supplied by the publisher. Release-package quirks are intentionally preserved in that import so later fixes can be recorded as separate commits.
